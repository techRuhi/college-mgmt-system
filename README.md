# 🎓 College Management System

A comprehensive web-based platform designed to streamline administrative tasks, manage student and teacher records, track attendance, and organize course details efficiently.

## ✨ Features

- **Dashboard Navigation:** Centralized main dashboard for quick access to institutional metrics and system modules.
- **Student & Teacher Management:** Easily add, view, and manage student profiles and faculty records.
- **Attendance Tracking:** Dedicated tracking systems for monitoring student and teacher attendance.
- **Course Management:** Browse and manage available courses and detailed curriculum structures.
- **Interactive Pages:** Smooth multi-page architecture with dedicated views for editing records, viewing details, and user assistance.

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **Bootstrap / Custom CSS Styling**
